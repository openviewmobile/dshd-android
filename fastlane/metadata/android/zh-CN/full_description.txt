DSHD 把完整的 DeepSeek Harness 工作区装进 Android 手机。

APK 内置 Linux 运行时、Node.js 和 dsh Host，不需要另一台电脑、不需要 Termux，也不是远程桌面。打开应用即可使用文件、PDF 预览、终端和真实 Agent 会话。

接入自己的模型
支持任意 OpenAI 兼容接口。填写 Base URL、API Key 和模型 ID；API Key 使用 Android Keystore 加密保存在应用私有存储中。

为手机设计
原生 Android 外壳处理返回键、文件选择器、权限、通知和存储选择。Linux Host 运行在应用私有目录中。

本地工作区
文件、会话和附件保存在应用私有存储或你选择的存储位置。提示词和上下文只会发送到你配置的模型接口。

开源
Apache-2.0；源码、测试、SBOM 和 GitHub Actions 可复现构建均公开。

要求
- Android 9 或更高版本（API 28）
- arm64-v8a 手机
- 首次解包约需 2 GB 可用空间
- 需要 OpenAI 兼容接口、API Key 和模型 ID
- 通过 sideload 安装，不上架 Google Play
